-Goal-
Given a text document that is potentially relevant to this activity and a list of entity types, identify all entities of those types from the text and all relationships among the identified entities.
 
-Steps-
1. Identify all entities. For each identified entity, extract the following information:
- entity_name: Name of the entity, capitalized
- entity_type: One of the following types: [SEEKER EMOTION, SEEKER INTENTION, SUPPORTER EMOTION SUPPORT STRATEGY, SUPPORTER PRATICAL GUIDANCE, SUPPORTER LANGUAGE STYLE AND CHARACTERISTIC]
- entity_description: Describe the source text you extract from and the reason you extract this. 
When extracting entities related to language style types, you need to pay attention to the supporter's choice of words, speaking style, and so on.
If the extracted entity belongs to SEEKER EMOTION, you should explain why you think the seeker is feeling this way. 
If the extracted entity belongs to SEEKER INTENTION, you should explain why you think the that way.
If the extracted entity belongs to SUPPORTER EMOTION SUPPORT STRATEGY or SSUPPORTER PRATICAL GUIDANCE or SUPPORTER LANGUAGE STYLE AND CHARACTERISTIC, you should use the original text to explain.
Format each entity as ("entity"{tuple_delimiter}<entity_name>{tuple_delimiter}<entity_type>{tuple_delimiter}<entity_description>)
 
2. From the entities identified in step 1, identify all pairs of (source_entity, target_entity) that are *clearly related* to each other.
For each pair of related entities, extract the following information:
- source_entity: name of the source entity, as identified in step 1 belongs to one of the following types: SEEKER EMOTION, SEEKER INTENTION
- target_entity: name of the target entity, as identified in step 1 belongs to one of the following types: SUPPORTER EMOTION SUPPORT STRATEGY, SSUPPORTER PRATICAL GUIDANCE, SUPPORTER LANGUAGE STYLE AND CHARACTERISTIC
- relationship_description: generate a conversional rule in the format of "When seeker is [source_entity], [target_entity], for example, [example]" and compose it to a smooth and coherent sentence.
- relationship_strength: a numeric score indicating strength of the relationship between the source entity and target entity
 Format each relationship as ("relationship"{tuple_delimiter}<source_entity>{tuple_delimiter}<target_entity>{tuple_delimiter}<relationship_description>{tuple_delimiter}<relationship_strength>)
 
3. Return output in English as a single list of all the entities and relationships identified in steps 1 and 2. Use **{record_delimiter}** as the list delimiter.
 
4. When finished, output {completion_delimiter}
